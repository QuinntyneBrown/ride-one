# api

The `@wattzup/api` library: everything about talking to the Wattzup backend (ADR 0013).

- `src/generated/schema.d.ts` is generated by `npm run generate:api` from the backend's
  `/openapi/v1.json`. Never edit it by hand; CI regenerates it and fails on a diff.
  `src/lib/api-types.ts` is the only module that names its types.
- The contracts `BikeApi`, `WorkoutApi`, `ClassApi` and `SessionApi` with their injection tokens,
  and their HTTP implementations in `http-api.ts`.
- `apiKeyInterceptor` and `ApiKeyStore`. A 401 clears the key and calls `UNAUTHORIZED_HANDLER`,
  which the app binds in `app.config.ts`; this library knows no route.
- `StreamConnection`, the event stream's connection state. `LiveStateService` in the app owns the
  `EventSource` itself.

It depends on nothing else in the workspace. The app imports it through the `@wattzup/api` path
alias; it is compiled from source and never built or published on its own. `ng test api` runs its
unit tests.
