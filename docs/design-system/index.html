How to use

  1. Link the tokens, then the components, on every page, and set the theme on the root: <html data-theme="dark">. Dark is the product's default; data-theme="light" opts in to the light theme.
  2. Use the classes exactly as each component page's Code section shows them. States assistive technology must know are attributes (aria-pressed, aria-current, aria-invalid, aria-busy, disabled); style through them, never through extra classes.
  3. Re-theme a component by overriding its component tokens (--btn-bg, --field-border, --dialog-width…), never its properties. Change what a role means in tokens.css, never in a component.
  4. Generate platform constants from tokens/tokens.json (W3C DTCG: $type, $value, aliases as {group.token}, theme overrides under $extensions).
  5. Add a colour pairing to tokens/contrast-pairs.json and run the contrast check before using it.
<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">

Press t on any page to switch the documentation between dark and light; add ?theme=light to a link to open it in light.
