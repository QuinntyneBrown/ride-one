How to use

  • Link tokens/tokens.css then assets/components.css; set data-theme on <html>.
  • Copy class names from each component's Code section; in Angular each component owns its block in its own stylesheet.
  • Read tokens by role (--color-fg-muted), never primitives or hex.
  • Import tokens/tokens.json into design tools.
