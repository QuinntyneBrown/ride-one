Pattern

Live data

Live data is the heart of Wattzup: power, cadence, resistance and time, updating once a second from one live state.

WCAG 2.2 AA

Overview

Replaces the kit's data-table pattern: Wattzup has no tables. Values come from LiveStateService (one live state, read from the bike in the page). Readouts, interval, trace, metrics and the level control all read the same signal. Numerals are condensed and tabular so digits do not jump.

When to use

  • Any value from the bike or the workout engine.

States

  • Live — full opacity.
  • Stale — bike lost: last values at --opacity-stale, a banner or overlay explains.
  • No data — "--" before a bike is connected or with Bluetooth off.
  • Requested vs reported — target resistance shown separately until the bike confirms.

Responsive

  • Hero numbers shrink at 360px but never truncate; four-digit power fits.

Accessibility

  • Live values are not live regions; step changes and failures are announced instead.
  • Timers use role="timer" with aria-live="off".
  • Charts have a text equivalent.
  • The animation loop pauses when the tab is hidden and respects reduced motion.

Content

  • Units always visible; real minus sign for deltas; m:ss and h:mm:ss.
