Pattern

Page structure

Every Wattzup page is one of three shells — ride, setup, centred card — with the same skip link, header and main landmark.

Overview

See page layout and app bar. There is no sidebar navigation: the product has two working screens, linked from the app bar (workout label → setup, Close → ride).

When to use

  • Ride (/): live numbers and bike control.
  • Setup (/setup): plan the ride.
  • Centred card: unlock and 404.

Structure

  1. Skip link.
  2. header: app bar.
  3. Optional banner region (connection banners).
  4. main: the screen.
  5. aside: the side panel (Bike control, Ride preview).

States

  • Every page has one h1 (visually hidden on ride, where the numbers are the content).

Responsive

  • One column under 1024px with the panel after main; from 1024px a fixed two-column shell where each column scrolls.

Accessibility

  • Landmarks: banner, main, complementary (labelled).
  • Reading order matches visual order at every width.
  • Page titles name the screen: "Ride — Wattzup".

Content

  • Panel labels name their job: Bike control, Ride preview.
