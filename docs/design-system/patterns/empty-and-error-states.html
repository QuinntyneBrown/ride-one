Pattern

Empty and error states

Empty and error states explain what is going on and offer one way forward, while keeping the app bar in place.

WCAG 2.2 AA
  • Overview
  • When to use
  • Structure
  • States
  • Responsive
  • Accessibility
  • Content
  • Do and don't
  • Sources

Overview

Three cases: nothing yet (no ride — Set up a ride), loading failed (Try again, Open diagnostics), and unknown route (404 — Back to the dashboard). Bike-specific stops (lost, scanning, Bluetooth off, ended) use the overlay panel.

When to use

  • No workout running: ride/empty.
  • Status failed to load: ride/error.
  • Unknown address: not-found.

States

  • Empty — explains what will appear and the action to make it appear.
  • Error — what failed, that the bike is unaffected, Retry.
  • 404 — reassurance and two ways back.

Responsive

  • Centred in the region it replaces at every width.

Accessibility

  • Error variants are role="alert"; empty ones are plain content.
  • The action is the next tab stop.

Content

  • Never blame the rider; say what is safe ("Your ride and the bike connection are unaffected").
