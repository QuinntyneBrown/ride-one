Foundation

Layout

Mobile first. Five breakpoints, a fluid grid with gutters and margins that grow with the screen, and two layout changes that matter: 640px (one row app bar) and 1024px (side panel).

  • Breakpoints
  • Grid
  • Page shells
  • All tokens

Breakpoints

NameMin widthWhat changes
base0One column; app bar wraps; icon-only actions; dialogs as sheets.
sm640pxLabels on app-bar actions; 3-column steppers; centred dialogs.
md768pxLarger gutters and margins.
lg1024pxSide panel (ride 340px, setup 420px); fixed shell.
xl / 2xl1280 / 1536pxContainer max; more breathing room.
