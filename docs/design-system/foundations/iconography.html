Sizes

  • sm 16px in buttons and status
  • md 20px default
  • lg 24px in toasts and empty states
  • xl 32px in overlay panels

Labelling

  • Icons next to text are aria-hidden.
  • Icon-only buttons carry aria-label and a tooltip.
  • State icons change shape, not only colour (bluetooth / bluetooth-off).
