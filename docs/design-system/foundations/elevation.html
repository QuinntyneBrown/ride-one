Foundation

Elevation

In dark, elevation is mostly lighter surfaces (panel → raised) with shadows as support; in light, shadows carry it.

  • Surfaces

Surfaces

  • Canvas → surface (panels) → raised (dialogs, toasts, tooltip-like) → sunken (code blocks).
  • Veil over the ride for overlays and the step-change banner.

Z-order

  • --z-base
  • --z-raised
  • --z-sticky
  • --z-dropdown
  • --z-overlay
  • --z-modal
  • --z-popover
  • --z-toast
  • --z-tooltip

Opacity

  • --opacity-disabled for every disabled control.
  • --opacity-stale for values that are no longer live.
  • --opacity-plan / -plan-past for target blocks in the trace.
