Foundation

Accessibility

WCAG 2.2 AA in both themes, by keyboard and by touch, with colour never the only cue.

  • Commitments
  • Focus
  • Testing
  • All tokens

Commitments

  • Text 4.5:1, large text and UI 3:1 — checked for every pair.
  • Visible focus ring on every control (2px, 2px offset).
  • Keyboard access to everything; dialogs trap focus and restore it.
  • Colour is never the only carrier: words, icons and shapes back it up.
  • Live values are not announced each second; step changes and failures are.
  • Reduced motion honoured.
  • Targets at least 24px, 44px for primary actions.
  • Auto-dismissing toasts last 8 s and pause on hover/focus.

Focus

Testing

  • Axe sweeps in Playwright (run when asked).
  • Manual keyboard pass on ride, setup and each dialog.
  • Screen reader check on the step-change announcement.
