Button

Buttons start, stop and change things: Start ride, End, Reconnect, Retry. One primary (volt) button per view says what matters most.

Overview

Use a button when activating it changes something on the bike, the ride or the screen. Use a link when it only goes somewhere (the workout label in the app bar is a link to setup). Use the level control for − / + on resistance.

  • Primary — volt fill, ink label. The one action the view exists for: Start ride, Reconnect, Set up a ride.
  • Secondary (default) — surface with a strong edge: Keep riding, Copy details, Open diagnostics.
  • Subtle — filled with the subtle surface and no edge: the − / + of number steppers.
  • Quiet — no fill, muted label; brightens on hover. App-bar actions (Pause, the workout label, icon buttons).
  • Quiet danger — quiet, turns heart red on hover: End in the app bar, which then confirms.
  • Link — a button that reads as a link: Back to plan.
  • Danger — heart fill: only the confirming End ride inside the end-ride dialog.

Anatomy

  1. Leading icon (optional)1.25em, inherits the label colour, aria-hidden.
  2. LabelVerb phrase, sentence case; the accessible name.
  3. ContainerHeight from --control-height-*, --radius-md, 1px edge (olive in light on primary).

Icon-only and collapsible

Icon-only buttons carry aria-label and a tooltip. Collapsible buttons show their label from 640px and only the icon below it, keeping the label as the accessible name.

Resize below 640px to see the collapsible button lose its label.

Block

Full width: the Start ride button at the foot of the ride preview.
HTML
<button class="btn btn--primary btn--xl btn--block" type="button">Start ride</button>

Sizes

Medium (40px) is the default. Small (32px) sits in dense rows (Back to plan). Large (48px) is for single-purpose screens (Unlock). Extra large (56px, --radius-lg) is reserved for Start ride.

States

Pointer and focus states are forced with data-state; real pages get them from :hover, :focus-visible, :active, :disabled and aria-busy.

Both themes

  • Loading keeps the width, hides the label behind a spinner, sets aria-busy and ignores clicks: Starting…, Ending…, Unlocking….
  • Disabled is 50% opaque and not focusable. Start ride is disabled while the setup form has errors, with the reason written under it (aria-describedby).
  • Pressed toggles (beeps) use aria-pressed and change their icon, never colour alone.

Responsive behaviour

  • Below 640px app-bar actions use .btn--collapsible: icon only, 40px square, label kept for assistive technology.
  • Start ride is full width (.btn--block) at every width inside the ride preview.
  • Dialog footers wrap; the primary stays last (rightmost, or bottom when wrapped).
  • Labels never truncate; a label that wraps at 360px is too long.

Theming

Variants set four component tokens — --btn-bg, --btn-fg, --btn-border, --btn-bg-hover (plus --btn-fg-hover, --btn-bg-active). Volt is a fill in both themes with an ink label; in light the primary edge is olive (--color-accent-edge) because volt on white is 1.1:1.

Accessibility

Role and pattern

Native <button type="button"> (type="submit" in the unlock form). A link styled as a button stays an <a href> (Set up a ride, Back to the dashboard).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceActivates. Space fires on key up, so moving away cancels a mis-press.

Focus

Shared ring: 2px --color-focus-ring (volt in dark, olive in light), 2px offset, on :focus-visible only. In dialogs the safe button (Keep riding) takes focus first.

Labelling

The visible label is the name. Icon-only buttons set aria-label ("Diagnostics", "Countdown beeps off"); collapsible buttons keep the label in .btn__label.

Motion

Colours change over --duration-fast; active nudges 1px. Durations are zeroed under reduced motion; the busy spinner keeps turning because it is status.

Touch

Medium is 40px with 8px between neighbours; app-bar and primary actions are 44px or more on phones. Small buttons only sit where the row around them is roomy.

Content

  • Verb first, sentence case: Start ride, Reconnect, Try again, Copy details.
  • Destructive labels name the result: End ride, Replace ride — not Confirm or OK.
  • The safe choice says what continues: Keep riding, Keep current ride.
  • Busy labels end in an ellipsis: Starting…, Ending…, Unlocking….
