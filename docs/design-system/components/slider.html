Slider

The level slider picks a resistance from 1 to 32 with the value shown large beside its label.

WCAG 2.2 AAStatus: stable

Overview

Native <input type="range"> tinted with accent-color: volt for work, rest blue for recover. Flat mode uses the large variant. Arrow keys give a single-pointer alternative to dragging.

Anatomy

  1. LabelBody-sm, muted.
  2. ValueNumeral md (xl when large) with "/ 32".
  3. TrackNative range, tinted.
  4. ScaleLight … Max.
