Class card and shelf

One class of the library, linked to its class page, on a shelf the catalogue defines.

Overview

A class card is one entry of the class library: a link to the class page that shows, before the rider commits, how long the ride is, what shape it has and how hard it gets. Cards sit on shelves, one per ride length, under a heading row with the length, a one-line blurb and a count.

Use it only for the library. A plan the rider builds on Set up your ride has no card. Proposed in the 2026-11-17 Magic Patterns frames; it needs a requirement before it is built (mocks README, open question 17).

Anatomy

  1. Cover (__cover): 16:9, the YouTube thumbnail built from the class's video id (ADR 0014); a __poster stands in when the class has no link or the thumbnail fails. The examples here use stand-in images.
  2. Length (__length): the plan's total time, on the video scrim.
  3. Plan strip (.profile): one block per segment, height by level; decorative.
  4. Title (__title): the video's name; turns accent on hover.
  5. Meta (__meta): channel · focus · peak level.
  6. Link note (__note): Video link not set, only when the entry has no YouTube link.

The shelf (.shelf) is the heading row (__head: __title, __blurb, __count) and a list of cards (__grid).

Hover zooms the cover to 103 % and turns the title accent; focus rings the cover. There is no disabled or selected card: every entry opens its page, even without a link. While the catalogue loads, a skeleton of the same size stands in for each card (see Skeleton).

Responsive behaviour

Gaps are 32 px between rows and 20 px between columns at every width. The library's own padding follows Page layout.

Accessibility

Role and pattern

Each card is a single link (WAI-ARIA link); the shelf is a section labelled by its heading, and its cards are a list. The shelf filter above the shelves is a tablist (see Video ride-along, view switch).

Keyboard

KeyAction
Tab / Shift+TabMoves through the cards in reading order, shelf by shelf.
EnterOpens the class page.

Focus

The ring is drawn on the cover, not the whole card, so it hugs the most visible part; it meets 3:1 against the page.

Labelling

The link's name comes from its text: length, title, meta and the note. The cover is decorative (alt="") and the strip is aria-hidden; the length is in the text, and the structure is on the class page.

Motion

The cover zoom takes --duration-base; under prefers-reduced-motion it does not move.

Touch

The whole card is the target, far above 44 × 44 px.

Content

  • Title: the video's own name, as published.
  • Meta: Channel · Focus · Peak L{n}; the focus is one or two words (HIIT, Zone 2, VO₂ max).
  • Length: m:ss, or h:mm:ss from an hour.
  • Note: exactly Video link not set.
  • Shelf: the length as a title (20 min, 60 min endurance), one sentence of blurb, and 1 video / n classes.
