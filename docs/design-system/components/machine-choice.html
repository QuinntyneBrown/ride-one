Machine choice

The machine choice is the Machine radio group at the top of Set up your ride: Bike or Treadmill. It comes before the training mode because it decides which fields follow (L2-072).

Overview

Use for the one machine-wide choice. It is a compact segmented radio group, not mode cards: the two options need no description, and it must not be confused with the training mode below it.

Anatomy

  1. Legend__legend, body-sm muted: “Machine”.
  2. Track__options, subtle fill, --radius-lg.
  3. Option__option: radio, icon, label; chosen: selected fill and edge.

Both themes

Machine
Machine
  • Locked: while a workout is active the whole fieldset is disabled and the help line says why.
  • Switching: choosing the other machine sends POST /api/machine; on failure the choice returns to the current machine and the alert shows.

Responsive behaviour

  • The track hugs its content at every width; on very narrow screens the options wrap.

Theming

Chosen option uses --color-selected-bg and --color-selected-border, the same roles as the mode cards.

Accessibility

Role and pattern

Native radios in a <fieldset> with a visible <legend> “Machine”: the APG Radio Group behaviour comes free. When locked, the fieldset is disabled and aria-describedby points at the help line.

Keyboard

KeyAction
TabInto the group, onto the checked option.
← → ↑ ↓Move and select; selecting switches the machine.

Focus

The option shows --shadow-focus when its radio has focus.

Labelling

The option text (Bike, Treadmill) is the radio's label; the icon is decorative.

Contrast

Option text on track
Chosen text
Chosen edge on track
Radio dot

Colour is not the only carrier: the chosen option also shows a filled radio dot.

Motion

Fill and edge over --duration-fast.

Touch

Each option is at least 44px high (--target-comfortable) and the whole option is the hit area.

Content

  • Legend “Machine”; options “Bike” and “Treadmill”.
  • Locked: “End the ride in progress to change the machine.”
  • Failure alert: “Couldn't switch the machine” / “The Wattzup server didn't answer. Try again.”
