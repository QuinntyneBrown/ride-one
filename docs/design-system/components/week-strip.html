Week strip

This week, Monday to Sunday: filled where the rider rode, outlined today.

Overview

The week strip shows the current week at a glance in the Session Summary's streak panel. Weeks start on Monday (L2-087). The six-week version is the Streak calendar.

Anatomy

  1. Day (__day): one per weekday.
  2. Bar (__bar): filled (--ridden), dashed for today, faint in the future.
  3. Label (__label): M T W T F S S; today in bold.

Accessibility

Role and pattern

An ordered list; each bar is role="img" named Wednesday 18 Nov, ridden. The letters are hidden from assistive technology.

Keyboard

KeyAction
—Not interactive; read in reading order.

Labelling

The name carries the state, so the fill is never the only carrier.

Contrast

Ridden bar edge

Motion

Colour and opacity changes only, over --duration-fast; none under prefers-reduced-motion.

Touch

No control is smaller than 44 × 44 px.

Content

  • Single letters for the days; the full date is in the name.
