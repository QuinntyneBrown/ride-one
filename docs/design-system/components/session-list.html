Session list

Overview

The session list shows the saved sessions newest first, eight at a time with Show all (L2-086).

Anatomy

  1. Head (__head): Sessions and n saved.
  2. Columns (__cols): Date, Ride, Time, Avg, On target, Dips.
  3. Row (__row): one link per session.
  4. More (__more): Show all n / Show fewer.

Sizes

States

Row: default, hover, focus. Ended early under the title for an unfinished ride.

Responsive behaviour

Under 576 px a row shows the title with the date and time beneath, then Avg and On target; from 576 px all seven columns.

Accessibility

Role and pattern

A list of links; the column header row is decorative (aria-hidden), each link reads its date, title and figures in order.

Keyboard

KeyAction
TabNext session.
EnterOpens it.

Labelling

The dips count is a number, never a colour alone.

Contrast

Date
Ended early

Motion

Colour and opacity changes only, over --duration-fast; none under prefers-reduced-motion.

Touch

No control is smaller than 44 × 44 px.
