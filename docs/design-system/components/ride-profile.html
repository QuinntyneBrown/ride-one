Ride profile

The ride profile previews the planned ride: total time in big numerals and each segment as a bar whose height is its resistance.

Overview

Updates as setup values change. Pairs with a split description list (Structure, Time under load, Peak resistance, Expected avg power, Expected energy) and a legend.

Anatomy

  1. TotalNumeral xl.
  2. BarsHeight = level of 32.
  3. AxisStart and total.
