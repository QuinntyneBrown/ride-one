Text field

A text field takes one line of text. Wattzup has one: the API key on the unlock page.

WCAG 2.2 AAStatus: stable

Overview

Always inside a form field with a visible label. The API key field is type="password" with autocomplete="current-password" so password managers fill it.

Anatomy

  1. Container48px (lg), 1px strong edge, --radius-md.
  2. ValueBody text; masked for keys.

Variants

Large: the unlock page.
HTML
<label class="field"><span class="field__label">API key</span><input class="input input--lg" type="password" autocomplete="current-password"></label>

Responsive behaviour

  • Full width of its form at every breakpoint.

Theming

--field-border aliases --color-border-strong, the focus ring or --color-danger-solid by state.

Accessibility

Role and pattern

Native <input> with <label>; help and error through aria-describedby; aria-invalid when rejected.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterSubmits the unlock form.

Focus

On load the unlock field has autofocus; the ring replaces the edge colour (0 offset).

Labelling

Visible label "API key"; help names where the key lives.

Content

  • Labels are nouns: API key.
  • Placeholders never replace labels.
