Text field

A text field takes one line of text. Wattzup uses it for the YouTube link on setup and on the class page.

WCAG 2.2 AAStatus: stable

Overview

Always inside a form field with a visible label. The YouTube link field is type="url", so phones offer a keyboard with / and .com.

Anatomy

  1. Container48px (lg), 1px strong edge, --radius-md.
  2. ValueBody text, as typed.

Variants

Large: a field that stands alone on its screen.
HTML
<label class="field"><span class="field__label">YouTube link</span><input class="input input--lg" type="url" autocomplete="url"></label>

Sizes

States

VariantDefaultHoverFocusInvalidRead-onlyDisabled
Text field

Both themes

Responsive behaviour

  • Full width of its form at every breakpoint.

Theming

--field-border aliases --color-border-strong, the focus ring or --color-danger-solid by state.

Accessibility

Role and pattern

Native <input> with <label>; help and error through aria-describedby; aria-invalid when rejected.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterSubmits the form; on setup, Start ride.

Focus

The ring replaces the edge colour (0 offset).

Labelling

Visible label "YouTube link"; the error says which links work.

Motion

Edge colour over --duration-fast.

Touch

Large is 48px tall.

Content

  • Labels are nouns: YouTube link.
  • Placeholders never replace labels.
