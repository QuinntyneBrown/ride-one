Alert and banner

Alerts explain a condition in place: a server error beside Start ride, an unlock failure, or as a full-width banner, the connection state.

Overview

Four tones. As .banner it spans the page under the app bar: simulated bike (info), reconnected (success), server unreachable (warning), Bluetooth off (danger), network-exposed server (persistent info).
