Chip

Chips are compact toggles. In setup, preset chips fill Rounds, Work and Recover in one tap; the chosen one stays pressed until a value is edited.

WCAG 2.2 AAStatus: stable

Overview

Use solid chips for presets that set several fields at once. They behave as a single-select toggle group (aria-pressed), not as radios, because no preset stays chosen once a field is edited. For one-of-two choices that change the whole form, use mode cards.

Anatomy

  1. Container44px tall, full radius, subtle fill.
  2. LabelPreset name; ink-on-chalk when pressed.

Variants

Solid chips: the setup presets.
HTML
<div class="chip-group" role="group" aria-label="Presets">
<button class="chip chip--solid" type="button" aria-pressed="false">Tabata</button>
<button class="chip chip--solid" type="button" aria-pressed="true">40 / 20</button>
<button class="chip chip--solid" type="button" aria-pressed="false">Minute on</button>
<button class="chip chip--solid" type="button" aria-pressed="false">Long climbs</button>
</div>

Outline

The base chip has an edge and a volt-tinted pressed state; kept for filters.

HTML
<div class="chip-group"><button class="chip " type="button" aria-pressed="true">Work</button><button class="chip " type="button" aria-pressed="false">Recover</button></div>

Sizes

Chips come in one size: 44px solid (touch target) or 32px outline.

Responsive behaviour

  • Chips wrap onto a second row at 360px; never scroll sideways.

Theming

Component tokens --chip-bg, --chip-fg, --chip-border. Pressed solid chips use --color-chip-on-bg/--color-chip-on-fg (chalk on ink in dark, ink on paper in light).

Accessibility

Role and pattern

Buttons with aria-pressed in a role="group" labelled "Presets".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceApplies the preset and presses the chip.

Focus

Each chip is a tab stop.

Labelling

The chip text is the name; the group has aria-label.

Touch

Solid chips are 44px tall with 8px gaps.

Content

  • Name presets by what riders call them: Tabata, Minute on, Long climbs.
  • Keep names to two words.
