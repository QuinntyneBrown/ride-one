Command log

The command log lists what Wattzup sent to the bike: time, RES level, plan or manual, and ack latency, sending or failed.

Anatomy

  1. HeadTitle + connection id.
  2. TimeRide time.
  3. CommandRES level · source.
  4. Resultack / sending / failed.
