Machine card

A machine card is one option of the machine page’s radio group: a photo, the machine’s kind and signal strength, its name and serial, what Wattzup controls on it, its last session and the action that picks it.

WCAG 2.2 AAStatus: stable

Overview

Use on the machine page (/machine, L2-073), one card per machine Wattzup can drive, inside a radiogroup. Picking a card connects to that machine. Use Machine choice for a compact choice inside a form; use a machine card when the rider picks a machine before anything else.

Anatomy

  1. Input (.machine-card__input): a visually hidden radio; the whole card is its label.
  2. Media (.machine-card__media): 16:9 photo with an optional tag (.machine-card__tag), such as Last used.
  3. Kind and signal (.machine-card__kind): Bike or Treadmill, and .signal-bars, four bars lit by signal strength.
  4. Name and serial (.machine-card__name, .machine-card__serial).
  5. Details: a split description list.
  6. Foot (.machine-card__foot): an optional error (.machine-card__error) and the call to action (.machine-card__cta).
Anatomy: the last-used bike, selected.

Sizes

One size. Cards share the row equally and keep a 16:9 photo; the call to action is --control-height-xl high, well above the 44 × 44 px target minimum.

States

Not found (failed, with Try again) and disabled while another machine connects.

Responsive

Cards stack in one column on a phone and sit side by side from 40 rem. The photo keeps its ratio; long names wrap.

Theming

Every colour is a semantic role, so the card follows the light and dark themes. The photo is the same in both.

Accessibility

Role and pattern

Native radios in a role="radiogroup" (APG Radio group). The details list describes the radio through aria-describedby.

Keyboard

KeyAction
TabMoves into and out of the group
↑ ↓ ← →Moves between machines
SpacePicks the focused machine

Signal

Signal bars are an image named Signal 3 of 4; strength is never carried by colour alone.

Errors

The error sits in the card, in text with an icon.

Content

Name the action by what happens: Ride the bike, Run on the Stride, Try again. The last session reads None yet when there is none.

Code

Angular: MachineCard (wz-machine-card) and SignalBars (wz-signal-bars) in @wattzup/components. The card takes the machine, its view (MachineCardView), its status (CardStatus), checked, disabled and loading, and emits pick and retry.
