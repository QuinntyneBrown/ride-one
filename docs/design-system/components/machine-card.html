Machine card

The machine card is one machine on Choose machine: photo, kind and signal, model, what Wattzup controls, the last session and the call to action.

Overview

Use one machine card per machine on Choose machine (L2-073): a photo, the machine kind with its signal strength, the model and serial, what Wattzup controls, the last session and the call to action. The cards together are one radio group; picking a card chooses that machine. Use the machine choice instead for the compact switch inside Set up your ride.

Choose machine: the bike was used last.

Anatomy

  1. Input__input, a visually hidden radio; the whole card is its label.
  2. Media__media, 16:9 photo with an optional __tag (Last used).
  3. Kind and signal__kind with the .signal-bars part: four bars, lit up to the signal strength, role="img" named Signal n of 4.
  4. Name and serial__name (h3) and __serial (mono caption).
  5. DetailsA split description list, referenced by the radio's aria-describedby.
  6. Foot__foot with the __cta, or __error and a Try again call to action.

Variants

Default and primary call to action: the last-used machine leads.
--failed: the machine did not answer; the foot carries the error and Try again.

Sizes

States

Default, hover, chosen.
Disabled while another machine connects; failed.

Responsive

One column below 40rem; the cards sit side by side from 40rem, each at least 16rem wide. The photo keeps 16:9 and crops with object-fit: cover. The call to action stays at the foot of the card, so two cards of different heights line their actions up.

Theming

The card is a surface (--color-bg-surface) with a hairline border; the chosen card uses --color-selected-border, the failed one --color-danger-border. The tag sits on --color-bg-veil over the photo in both themes.

Accessibility

Role and pattern

Native radios in a <fieldset> with a legend: the APG Radio Group. The card is the radio's <label>; the details list is its description.

Keyboard

KeyAction
TabInto the group, onto the chosen card.
← → ↑ ↓Move between cards and choose.
SpaceChoose the focused card.

Focus

The card shows --shadow-focus while its radio has keyboard focus.

Labelling

The radio is named by the card text; the photo has empty alt; the signal bars are one image named Signal n of 4, so colour is not the only carrier of strength.

Contrast

Name on surface
Primary call to action
Error text

Touch

The whole card is the target, far above 44 × 44 px.

Content

Kind in sentence case (Bike, Treadmill). The call to action names the machine: Ride the bike, Run on the Stride. The error says what to check, in one sentence: The Stride isn’t answering. Check it’s switched on and the safety key is clipped in.
