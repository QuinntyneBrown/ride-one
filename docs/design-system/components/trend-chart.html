Trend chart

One point per finished attempt at a class, oldest left; the latest is larger.

Overview

The trend chart shows how one measure (average power, cadence on target or cadence dips) changed across the finished attempts at a class (L2-086). Each point is a link to that session.

Anatomy

  1. Figure (__figure): the latest value and unit.
  2. Change (__change): the signed change since the first ride and the count.
  3. Plot (__plot): three gridlines with labels, the line and one point per attempt.
  4. Axis (__axis): the dates.

Sizes

States

Point: default, hover (dot grows), focus (ring). The latest point is larger and filled.

Responsive behaviour

The plot stretches; under 576 px only the first and last dates may be shown when there are more than six.
