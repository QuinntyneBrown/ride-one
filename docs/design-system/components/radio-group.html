Radio group (mode cards)

Mode cards are a radio group drawn as cards: HIIT intervals or Flat resistance. The choice changes the whole setup form.

WCAG 2.2 AAStatus: stable

Overview

Use for a one-of-few choice that reshapes what follows. Real radio inputs inside labels; the card styles itself with :has(input:checked).

Anatomy

  1. Card1px edge, --radius-lg; selected: volt edge.
  2. Radio16px native radio, restyled.
  3. Title and descriptionSemibold title, muted body-sm.

Variants

Training mode
The setup mode choice.
HTML
<fieldset class="mode-cards">
<legend class="visually-hidden">Training mode</legend>
<label class="mode-card">
<span class="mode-card__title">
<input type="radio" name="mode" checked>HIIT intervals</span>
<p class="mode-card__text">Hard and easy efforts on repeat. Resistance switches at every interval.</p>
</label>
<label class="mode-card">
<span class="mode-card__title">
<input type="radio" name="mode">Flat resistance</span>
<p class="mode-card__text">One level, held the whole ride. You set the pace with your legs.</p>
</label>
</fieldset>

Sizes

One size; the card grows with its text.

States

VariantDefaultHoverFocus
Unselected
Selected
Disabled (submitting)

Both themes

Responsive behaviour

  • One column below 640px, two from 640px.

Theming

Selected uses --color-selected-border and --color-selected-bg: volt edge on raised in dark, olive edge on volt wash in light.

Accessibility

Role and pattern

Native radios in a <fieldset> with a (visually hidden) <legend> "Training mode". APG Radio Group behaviour comes free.

Keyboard

KeyAction
TabInto the group, onto the checked card.
← → ↑ ↓Move and select.

Focus

The card shows --shadow-focus when its radio has focus.

Labelling

Card title is the radio's label; the description is part of the label text.

Contrast

Selected edge
Text on selected
Description on selected

Motion

Edge colour over --duration-fast.

Touch

The whole card is the hit area.

Content

  • Title names the mode; description says what it does to resistance.
