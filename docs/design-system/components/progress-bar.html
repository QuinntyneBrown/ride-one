Progress bar

Progress bars show how far through something the rider is — mostly the current interval.

WCAG 2.2 AAStatus: stable

Overview

Thin (6px) kind-coloured bars in the interval block; standard (8px) bars for anything else.

Anatomy

  1. Track--color-track.
  2. FillKind or status colour.

Variants

Work, recover, easy.
HTML
<div class="progress progress--thin progress--work" role="progressbar" aria-label="Interval progress" aria-valuemin="0" aria-valuemax="100" aria-valuenow="17" style="width: 100%;">
<div class="progress__bar" style="--value: 17%;">
</div>
</div>
<div class="progress progress--thin progress--rest" role="progressbar" aria-label="Interval progress" aria-valuemin="0" aria-valuemax="100" aria-valuenow="60" style="width: 100%;">
<div class="progress__bar" style="--value: 60%;">
</div>
</div>

</div>
</div>

Standard

Determinate and indeterminate.
HTML
<div class="progress " role="progressbar" aria-label="Upload" aria-valuemin="0" aria-valuemax="100" aria-valuenow="40" style="width: 100%;">
<div class="progress__bar" style="--value: 40%;">
</div>
</div>
<div class="progress progress--indeterminate" role="progressbar" aria-label="Loading" aria-valuemin="0" aria-valuemax="100" aria-valuenow="0" style="width: 100%;">
<div class="progress__bar" style="--value: 0%;">
</div>
</div>
