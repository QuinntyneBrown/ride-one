Form field

A form field wraps one control with its label, help and error so every input in Wattzup reads the same way.

WCAG 2.2 AAStatus: stable

Overview

The wrapper (.field) stacks label → control → help → error with 4px between. Number steppers and sliders use their own heads but the same help and error parts.

Anatomy

  1. Label--text-label.
  2. ControlText field, stepper, slider.
  3. HelpMuted, body-sm.
  4. ErrorDanger text with ⚠, names the fix.

Variants

With help.
HTML
<label class="field">
<span class="field__label">API key</span>
<input class="input" type="password" aria-describedby="h1">
<span class="field__help" id="h1">Find it under Wattzup:Security:ApiKey.</span>
</label>

Sizes

The field takes the size of its control.

Theming

Help reads --color-fg-muted; error reads --color-danger-fg.

Accessibility

Role and pattern

<label> wraps or points at the control; help and error ids go in aria-describedby.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.

Focus

Focus goes to the control, never the label.

Labelling

Error text is announced with the control because it is in aria-describedby.

Contrast

Error on canvas
Help on canvas

Motion

None.

Touch

Label is part of the hit area.

Content

  • Errors name the field's rule and the fix: "Enter 1 to 30 rounds."
  • Help says where to find things, not what the label already says.
