Page layout

Page layouts are the three shells Wattzup uses: ride (main + resistance panel), setup (form + ride preview) and centred card (unlock, 404).

Overview

.app is a full-height column with the app bar. .ride-layout and .setup-layout are one column on phones and gain a fixed side panel from 1024px (340px and 420px), each side scrolling on its own. .auth-layout centres one card. .stack and .cluster space children.

Anatomy

  1. MainReadouts, trace, metrics.
  2. PanelResistance; below main on phones.

Responsive behaviour

  • Under 1024px the panel follows the main column and the page scrolls as one.
  • From 1024px the shell is fixed to the viewport (.app--fixed) and each column scrolls.

Theming

Panels use --color-bg-surface against the canvas.

Accessibility

Role and pattern

Landmarks: header (app bar), main, and the panel as <aside aria-label>.
