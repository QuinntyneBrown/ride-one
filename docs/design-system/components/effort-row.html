Effort row

An effort row sets one treadmill effort of a plan — Work, Recover, or Steady’s Hold: a speed typed or stepped between Slower and Faster, its pace, and an 11-bar incline picker from 0 to 10 %.

WCAG 2.2 AAStatus: stable

Overview

Use on the treadmill’s setup screen, one row per effort of the plan. The bike uses sliders for the same job; the treadmill needs a decimal speed and an incline, so the row pairs a stepper-like speed field with a level picker in its incline variant.

Anatomy

  1. Title (.effort-row__title) with the effort’s swatch.
  2. Speed head: the label and the pace (.effort-row__pace).
  3. Speed (.effort-row__speed): Slower, the input with its unit, Faster.
  4. Incline head with the value (.effort-row__incline).
  5. Incline picker: .level-picker--incline, 11 bars.

Responsive

Speed and incline stack on a phone and sit side by side from 40 rem (.effort-row__grid).

Theming

Colours are semantic roles; the swatch tones are the plan tones work, rest and steady in both themes.

Accessibility

Role and pattern

Each row is a group named by its title. The speed is a labelled text input with Slower and Faster buttons named for the row (Slower Work). The incline is one slider (APG Slider) with a value text such as Work incline 2% of 10%.

Keyboard

KeyAction
TabSlower, speed, Faster, incline
Enter in the speedSubmits the form
← → Home EndChange the incline

Errors

The error is text tied to the input with aria-describedby, never colour alone.

Content

Titles are the plan’s words: Work, Recover, Hold. Speed is in km/h with one decimal; pace is min:s per km.

Code

Angular: EffortRow (wz-effort-row) in @wattzup/components. It takes the row id, title, tone, large, the speed and incline as typed, an error and disabled, with the pace, incline and step limits computed by the app (EffortRowView); it emits speedChange, step, inclineChange and submitted.
