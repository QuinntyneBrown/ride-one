Level row

A compact stepper for one level of a plan before the ride: work, recover or steady.

Overview

A level row sets one level of a plan before the ride: work, recover, or the single steady level. It is the compact cousin of the Level control, which drives the bike's resistance live during a ride with 64 px buttons and a large numeral.

Use it in the plan panel of a video's page, where two or three levels stack in a narrow column. Use the level control on the ride dashboard and the Slider on Set up your ride.

Anatomy

  1. Name (__name): the series swatch and Work, Recover or Steady.
  2. Lower (.btn--subtle.btn--icon): one level down.
  3. Value (__value): the level and / 32.
  4. Raise (.btn--subtle.btn--icon): one level up.

Variants

Work24 / 32
Recover6 / 32
Interval plan: work and recover.
Steady12 / 32
Steady plan: one row.

Sizes

One size: 44 px buttons and the medium numeral.

States

VariantDefaultHoverActiveFocusDisabled
Step button
Work32 / 32
Recover1 / 32
At the limits: Raise is disabled at 32, Lower at 1.

While Start ride is in flight every button is disabled.

Responsive behaviour

The row is a four-column grid (name 5.5rem, button, value, button) and keeps it at every width: under 1024 px the plan panel sits below the video at full width, so the value column simply grows.

Buttons on --color-bg-subtle; swatches are the series colours, the same ones the plan profile uses.

Accessibility

Role and pattern

Two buttons and a live value (aria-live="polite") inside a group labelled Resistance. Not a slider: the rider changes one level at a time.

Keyboard

KeyAction
Tab / Shift+TabMoves between Lower and Raise of each row.
Enter, SpaceOne level down / up.

Focus

Focus stays on the button pressed, also when it reaches its limit and is disabled; the value is announced.

Labelling

Lower work resistance / Raise work resistance; the value reads Work level 24 of 32. The swatch is decorative: the name carries the meaning.

Contrast

Value on panel
/ 32
Focus ring on panel

Motion

Colour changes only, over --duration-fast.

Touch

Buttons are 44 × 44 px (--target-comfortable); the frame drew them at 40 px.

Content

  • Names: Work, Recover, Steady, the spec words for the segment kinds.
  • Value: the bare level and / 32; never L24 here, which is the card's short form.
