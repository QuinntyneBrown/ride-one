Status line

The status line says which bike Wattzup is talking to and the state of the link (ble).

WCAG 2.2 AAStatus: stable

Overview

Icon + name + state. Colour is never alone: the icon changes (bluetooth / bluetooth-off / wifi-off) and the state is a word.

Anatomy

  1. Icon16px; volt, warn or heart.
  2. NameBike name, truncates at 16rem.
  3. StateMuted word, coloured when not connected.
