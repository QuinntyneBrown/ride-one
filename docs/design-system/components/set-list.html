Set list

The ordered rows of an intervals plan: the warm-up, each set, and the cool-down. Each row states its values and carries its own actions; editing happens in a dialog.

WCAG 2.2 AAStatus: new

Overview

Use on the setup screen in Intervals mode. The list never edits values inline: Edit and Add set open a dialog (AGENTS.md, no inline forms). The warm-up and cool-down rows carry their on/off switch.

Anatomy

  1. Head: Set <i>, or the switch and name of the warm-up or cool-down.
  2. Value: the work line in the work colour and the recover line muted; both are text, so colour is never the only carrier.
  3. Actions: Edit, Move up, Move down, Remove, each a 44 × 44 px target.
  4. Add set: below the list.

Variants

  1. 5:00 · Level 8 · 80 rpm
  2. Set 11 × 0:30 · L28 · 100 rpmRecover 3:00 · L8 · 72 rpm
  3. Set 21 × 0:30 · L28 · 100 rpmNo recover
Stretch row (.set-row--stretch) and set rows.

Sizes

One size.

States

  • Default: as above.
  • First and last set: Move up or Move down is disabled.
  • One set left: Remove is disabled.
  • Ten sets: Add set is disabled.
  • Invalid plan: the list gets aria-invalid="true" and aria-describedby to a field__error (e.g. At most 30 efforts in a plan.); its top border turns danger.
  1. Set 18 × 0:30 · L28 · 100 rpmRecover 1:30 · L8 · 72 rpm

At most 30 efforts in a plan.

Responsive behaviour

  • Under 768 px the value moves below the head and actions, so the actions keep their 44 px targets.

Theming

Dividers --color-border-default; work line --color-series-work; recover line and stretch rows --color-fg-muted; invalid edge --color-danger-border.

Accessibility

An ordered list named Plan. Every action names its row (Edit set 2, Move set 2 up, Remove set 2) through visually hidden text or aria-label. After a move, focus stays on the moved row's same button; after a remove, focus goes to the next row's Edit (or Add set). A dialog returns focus to the button that opened it.

Content

  • Work line: <rounds> × <m:ss> · L<level> · <rpm> rpm.
  • Recover line: Recover <m:ss> · L<level> · <rpm> rpm, or No recover.
  • Stretch: <m:ss> · Level <n> · <rpm> rpm.

Do and don't

  • Do open a dialog to edit a row.
  • Don't put steppers inside the rows.

Tokens

--space-3 row padding, --target-comfortable row and action height, --border-width-hairline dividers.
