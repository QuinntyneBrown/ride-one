Empty state

Empty states explain why a region is empty and offer one way forward: No ride yet → Set up a ride.

Overview

Icon, title, one sentence, one primary action. The error variant keeps the chrome and offers retry plus diagnostics.

  2. Titleh3 (h4 compact).
  3. TextOne sentence.
