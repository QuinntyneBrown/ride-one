Stat strip

The totals of a ride as a row of labelled numerals.

WCAG 2.2 AAStatus: L2-085, L2-086

Overview

The stat strip lists a session's totals: time, best 1 minute, max power, average cadence, distance and energy. Heart rate is not shown: Wattzup has no sensor (ADR 0003).

Anatomy

  1. Label (__label): the stat's name.
  2. Value (__value): the numeral.
  3. Unit (__unit): W, rpm, km, kcal.

Role and pattern

A description list: dt label, dd value.

Keyboard

KeyAction
—Not interactive; read in reading order.

Labelling

Units are text next to the value.

Label

Motion

Colour and opacity changes only, over --duration-fast; none under prefers-reduced-motion.

Touch

No control is smaller than 44 × 44 px.

Content

  • Time, Best 1 min, Max power, Avg cadence, Distance, Energy.
  • Distance with one decimal.
