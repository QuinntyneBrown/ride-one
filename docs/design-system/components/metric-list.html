Metric list

The metric list shows the secondary numbers: heart rate, average power, speed, distance, energy.

Overview

A <dl> grid: 2 columns on phones, 5 from 640px. Values use small numerals with units. (Power, heart rate, distance and energy await requirements — see the mocks' open questions.)

Anatomy

  1. TermCaption, muted.
  2. ValueNumeral sm.
  3. UnitCaption, subtle.
