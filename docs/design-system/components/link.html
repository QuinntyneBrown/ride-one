Link

Links take the rider somewhere — to setup, back to the dashboard, or to the field an error summary names. They are underlined in running text.

Overview

Use a link for navigation. Volt in dark, olive in light, always underlined inside text so colour is not the only cue. A link that looks like a button (Set up a ride) is still <a href>; see button.

Anatomy

  1. LabelSays where it goes.
  2. Underline1px, 2px on hover; offset 0.15em.
