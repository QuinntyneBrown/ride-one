# Atacama Desert rendering

The live 3D world behind the ride HUD for [Extreme Fat Burning Class](http://localhost:4200/classes/extreme-fat-burning-class?simulate), which rides the salar road. The world follows its description: the driest desert on earth, salt flats and flamingo lagoons. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-atacama.ts`, with `build`, `lay`, `place`, `setTime` and `sink`, seeded detail, canvas textures, the kit's `Figures` for the visitors, and a loop that recycles the salt flat. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/extreme-fat-burning-class?simulate`, click **Ride in Atacama Desert**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
