# Sixth Street, Austin rendering

The live 3D world behind the ride HUD for [Get Pumped With Grace](http://localhost:4200/classes/get-pumped-with-grace?simulate), which rides down Sixth Street in Austin. The world follows its description: live-music bars and festival crowds spilling into the street. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-austin.ts`, with `build`, `lay`, `place` and `setTime`, seeded detail, canvas textures, the kit's `Figures` for the crowd and the band, and a loop that recycles the block. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/get-pumped-with-grace?simulate`, click **Ride in Sixth Street, Austin**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
