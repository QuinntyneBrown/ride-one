# Antwerp Port Sprint rendering

The live 3D world behind the ride HUD for [Lead Out Efforts Into Full Sprints](http://localhost:4200/classes/lead-out-efforts-into-full-sprints?simulate), which rides the quay road. The world follows its description: flat docklands roads and a bunch-sprint finish in Antwerp. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-antwerp.ts`, with `build`, `lay`, `place`, `setTime` and `sink`, seeded detail, canvas textures, the kit's `Figures` for the crowd, and a loop that recycles the port. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/lead-out-efforts-into-full-sprints?simulate`, click **Ride in Antwerp Port Sprint**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
