# Winterlude, Ottawa rendering

The live 3D world behind the ride HUD for [Aerobic Efforts With Max Sprints](http://localhost:4200/classes/aerobic-efforts-with-max-sprints?simulate), which rides beside the Rideau Canal. The world follows its description: snow sculptures and skaters on the frozen Rideau Canal. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-winterlude.ts`, with `build`, `lay`, `place`, `setTime` and `sink`, seeded detail, canvas textures, the kit's `Figures` for the skaters and walkers, and a loop that recycles the festival. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/aerobic-efforts-with-max-sprints?simulate`, click **Ride in Winterlude, Ottawa**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
