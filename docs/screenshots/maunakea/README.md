# Mauna Kea rendering

The live 3D world behind the ride HUD for [60 Minutes of Brutal Power](http://localhost:4200/classes/60-minutes-of-brutal-power?simulate), which rides the summit road. The world follows its description: a brutal climb past observatories to Hawaii's highest summit. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-maunakea.ts`, with `build`, `lay`, `place`, `setTime` and `sink`, seeded detail, canvas textures, the kit's `Figures` for the stargazers, and a loop that recycles the summit road. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/60-minutes-of-brutal-power?simulate`, click **Ride in Mauna Kea**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
