# Els Àngels, Girona rendering

The live 3D world behind the ride HUD for [Drop Ollie at All Costs](http://localhost:4200/classes/drop-ollie-at-all-costs?simulate), which climbs Els Àngels. The world follows its description: a favourite pro training climb above Girona's old town. It is built on the shared street kit (`world-kit.ts`) on the pattern of Old Town Criterium: one module, `world-angels.ts`, with `build`, `lay`, `place`, `setTime` and `sink`, seeded detail, canvas textures, the kit's `Figures` for the locals, and a loop that recycles the climb. Each capture is the same opening frame of the ride at 1440 × 900 on Three.js's WebGL2 backend, and each iteration is merged in its own pull request.

## Reproducing a capture

Build the app (`npm run build` in `frontend/`), serve `dist/wattzup/browser` on port 4300 with `node scripts/serve-dist.mjs 4300`, open `/classes/drop-ollie-at-all-costs?simulate`, click **Ride in Els Àngels, Girona**, wait for `/world`, let the scene settle for eight seconds and capture the viewport at 1440 × 900.
